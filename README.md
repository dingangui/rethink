# rethink

`$rethink` 是一个中文 Codex skill。如果你已经想好了一个做法，但还想找人帮你看看有没有遗漏，可以把需求交给它。它会先核实上下文，再判断这个做法能否达到你的目标。意图明确、改动容易撤回时，它会直接完善并执行。遇到会影响结果的取舍时，它会给出理由和选项，等你拍板。

## 安装

在 Codex 对话框中发送这条消息。

```text
$skill-installer https://github.com/dingangui/rethink/tree/main/skills/rethink
```

## 使用

在下一条消息里，把 `$rethink` 放在需求前面。

```text
$rethink 把这份实验报告压成一页。明天开会，我们要决定还要不要继续跑。
```

为了让读者明天能拍板，Codex 会把继续或暂停的建议放在这一页的开头，接着列出支持判断的数据，并指出哪项缺失的证据可能改变结论。

如果已经聊了几轮，也可以单独发 `$rethink`，让 Codex 结合刚才的需求、修正和已完成的工作重新审视方案。
